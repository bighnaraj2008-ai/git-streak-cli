# 🔥 Git Streak & Activity Analyzer

A lightweight command-line tool written in Python that analyzes your local Git repository history and visualizes your coding activity with a terminal-based contribution heatmap.

---

## 🚀 Features
* **Local Activity Tracking:** Parses `git log` data to evaluate your commit frequency over the past week.
* **Terminal Heatmap:** Renders an intuitive block-based visual representation of your daily output right in your console.
* **Zero Dependencies:** Built entirely with Python's standard library (no heavy third-party packages required).

---

## 🛠️ Tech Stack
* **Language:** Python 3
* **Tools:** Git, Subprocess API

---

## 📦 Getting Started

### 1. Clone the Repository
git clone https://github.com/bighnaraj2008-ai/git-streak-cli.git,
cd git-streak-cli

### 2. Run the Script
Navigate into any active Git repository or keep it here, then run:
python main.py
